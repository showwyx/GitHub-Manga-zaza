## Ep.6 MY-NAME-IS-NOT-DOG

ในคืนสุดท้าย ก่อนสงครามระหว่างเงา และความจริงจะระเบิด
น้องจิ้งจอกยืนอยู่ต่อหน้าบอสอีกครั้ง บอสที่ยังไม่รู้จักเขาได้พูดว่า
“นายเป็นใคร?”
“คนที่นายเคยรู้จักในอีกโลกหนึ่ง”
“ฉันไม่สนใจอดีตหรืออนาคต ฉันสนแค่ว่าตอนนี้นายกำลังข่มขู่ฉัน

บอสยังเป็นบอสเด็ดขาดและไม่ไว้ใจใครง่าย ๆ
แต่ก่อนที่การปะทะจะเกิดขึ้น เงาในชุดสูทดำปรากฏตัว
บอสเกือบถูกยิงจากด้านหลัง
แต่จิ้งจอกเข้าขวางไว้ รับกระสุนแทนโดยไม่ลังเล

เลยเกิดการยิงโต้กัน
เสียงปืนดังต่อเนื่อง ศัตรูพ่ายแพ้ แต่จิ้งจอกทรุดลง
บอสยืนอยู่ข้างเขา มือหนึ่งกุมบาดแผล มือหนึ่งจับมือเขาแน่น
แล้วพูดว่า “ฉันไม่รู้ว่านายเป็นใคร แต่ถ้าใครกล้า ยอมตายเพื่อฉัน.”
“นั่นไม่ใช่หมา นั่นคือ ‘คนของฉัน’”

ดวงตาของจิ้งจอกเปล่งแสงสีเงินครั้งสุดท้าย
ก่อนที่เงาทั้งหมดจะกลืนร่างเขากลับไปยังความว่างเปล่า

เหลือเพียงเสียงหนึ่งที่ก้องในหัวบอส
“บางครั้งศรัทธาไม่ได้อยู่ที่ปลายทาง
แต่อยู่ตรง คนที่กล้าก้าวเดินตั้งแต่แรกต่างหาก”
ในจักรวาลที่แตกแยก
จิ้งจอกได้เลือกแล้วว่าจะปกป้องศรัทธา
แม้จะไม่ได้อยู่ในโลกนั้นอีกต่อไป

บทสุดท้ายซ:

“ชื่อของเขา”
ไม่เคยเป็น “หมา”
แต่คือ “ศรัทธาที่กล้าเปลี่ยนโลก
