## Ep.5-Shadow-in-the-Mirror

ความเดิมจากตอนที่แล้ว น้องจิ้งจอกเหมือนจมดิ่งไปในมิติแห่งความมืด รอบกายเต็มไปด้วยเส้นทางที่แตกแขนง เหมือนกระจกที่แตกนับพันชิ้น

มีเสียงหนึ่งดังขึ้นจากความมืด ไม่ใช่ศัตรู ไม่ใช่เพื่อน แต่มันคือเสียงของพวกผมเอง
ที่ได้ให้ “พลังแห่งโลกคู่ขนาน” พลังที่เชื่อมเส้นเวลา และฉีกกฎแห่งความจริง แต่ต้องแลกกับการขายวิญญาณ

น้องจิ้งจอกลุกขึ้นยังไม่ลังเล แล้วได้พูดว่า "ฉันจะพาบอสกลับมา…"
แล้วน้องจิ้งจอกก็ได้ใช้พลังวาปกลับไปยังเมืองที่คุ้นตา 

แต่ไม่เหมือนเดิม
ที่นี่บอสยังไม่ตาย แต่กลับไม่รู้จักเขาอีกแล้ว
"นี่คือโลกที่บอสไม่ต้องเจอกับฉัน"
"หรือว่านี่โลกที่ดีกว่า"
น้องจิ้งจอกเฝ้าดูอยู่เงียบๆเขาไม่กล้าทักไม่กล้าเข้าใกล้

จนกระทั่งค่ำวันหนึ่งเขาเห็นบางอย่างที่ทำให้หัวใจแทบหยุดเต้น
ชายในชุดสูทดำคนนั้นคนที่จัดฉากหลอกเขาในโลกเดิม
กำลังเดินข้างบอสยิ้มให้เหมือนเพื่อนสนิท

น้องจิ้งจอกพูด
"ถ้าฉันไม่ทำอะไรโลกนี้ก็จะลงเอยเหมือนเดิม"
